2026-11-25 在独立试用库中建立三个事件，创建时来源全部留空。研究通过本机 DSH 调用 CANNBot 的 Kimi K3.1 Pro，预测与核验通过 Codex 的 kprsi 配置。两者均使用测试档的低思考强度。三个事件共使用 22 次真实调用，最终各登记一题可核验的预测。这里的结论数按已发布档案里带原文引文的条目计算。

| 事件 | 入选来源 | 带引文的条目 | 模型调用 | 累计模型调用耗时 |

## 确定性回放与浏览器

| 场景 | 核对结果 |
| --- | --- |
| 建档与找源 | 可从空订阅创建。规划器可以挑选巡检平台、解释理由、检索缺失的发布方，并遵从用户固定的平台选择。 |
| 角色与证据 | 八类角色均经同一真实队列执行。三个月前的专项公告可进入历史档案。引文须逐字命中提供给该角色的片段。数字 PDF 指向页码，发布方字幕指向原视频时间段。 |
| 窗口与突发 | 已覆盖边界、缺时区、仅日期、旧闻新发、转载和来源更正。两个事件共享一次平台轮询。重大公告及三篇转载触发一轮，另一条独立重大公告仍能在冷却期间触发。 |
| 改目标和断点 | 同轮研究时连续改目标会淘汰旧判断。分别在抓取落盘后、模型回执落盘后、发布事务提交前及提交后模拟进程丢失。恢复后每轮只发布一次。 |
| 预测与退出 | 决定性材料到达后，相关题的概率修订进入等待。受控案例中首次公开前的有效概率为 65%，结果为真，Brier 为 0.1225。归档后仍能结算开放预测，复盘经验可附上独立案例的反例。 |
| 前端阅读 | 浏览器从“新建追踪”留空 RSS，直接进入排队的初始化轮次。知识页可提交带理由和引文的订正，切回旧快照显示原话，比较栏显示新增一条、移出一条。390 像素视口核对了知识章节与引文入口。 |
