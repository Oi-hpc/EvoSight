# 世界知识目录与 Agent 检索

追踪任务共享一份世界知识。Agent 要能回答三个具体问题。一条旧知识在哪里，它有哪些可读字段，某次预测当时引用了哪段证据。目录按知识的内容组织。每个事件在自己的快照里保存条目编号、版本编号、章节和采用理由。同一份统计数据可以同时进入物价跟踪和消费行业跟踪，两边可以给出各自的采用理由。

## 内容目录和条目

| 内容主类 | Agent 可以沿目录找到的内容 |
| --- | --- |
| 人物 | 身份与背景、公开立场、近期行动、公开关系 |
| 组织机构 | 职责与权限、治理与人事、业务与决策 |
| 国家与地区 | 地理与区域、管辖与边界 |
| 制度与政策 | 草案与征求意见、通过与生效、执行与监管 |
| 指标与数据 | 物价下分居民消费价格与工业生产者价格，另有产出与增长、就业与人口、市场与利率 |
| 事实与进展 | 科技与产品下分软件版本发布与产品上市，另有建设与运营、公告与决定 |
| 舆情与观点 | 公开发言、平台与样本 |
| 关系与依赖 | 主体之间的关系、事件之间的关系、预测依赖 |
| 分析与假设 | 假设与解释、反证与争议、情景与条件 |
| 背景知识 | 历史脉络、方法与口径、标准与规范 |

首版注册 10 个主类和 34 个子目录。路径是面向 Agent 的稳定字符串，例如 `indicators/prices/consumer`。每个版本有一个主目录。涉及 CPI 与 PPI 的一条综合结论可以放在共同的“物价”目录。一次统计发布也可以产生两条分别可引用的指标记录。每个事件都能引用任一条目。[目录和类型注册表](../evosight/world_catalog.py)

类型表示该条目写了什么。知识性质表示它是事实、转述、观点、假设、关系、订正还是冲突。公开任职和有来源的行动可以作为人物资料；有关目的和心理动因的解释须作为带理由的分析假设保存。事件索引章节表示它对本次跟踪的用途。同一条经济数据可以出现在事件甲的新闻章节、事件乙的背景章节。

## Agent 怎样取到正确的字段

以“十月居民消费价格同比是多少，原文在哪里”为例。

1. 调用 `GET /api/world/route?q=CPI`。可在还没有条目时定位到“指标与数据 → 物价 → 居民消费价格”。响应给出稳定路径、类型、命中词及匹配的字段。只有字段名时也可查，比如“统计期”能定位到指标类型。
2. 调用 `GET /api/world/schemas/indicators`。可见 `value` 是数值，`unit`、`period`、`comparison` 和 `region` 是独立字段。类型与字段名具有版本号。
3. 调用 `GET /api/world/search?q=CPI&path=indicators/prices/consumer`。先看主体、结论摘要、知识性质、条目与版本编号。精确找某一期时，传 JSON 查询参数 `qualifiers={"period":"2026-10","comparison":"同比"}`，由 HTTP 客户端编码。最多可联合四个该类型定义的字段。地区、统计期和发生日期分别筛选。检索键识别“2026年10月”和“2026-10”是同一个统计月，读回的字段保留来源写法。需要找尚缺字段的旧资料时，可沿上一级目录放宽条件。
4. 根据查询返回的真实编号向 `POST /api/world/records` 提交 `records`，同时指定 `fields=["value","unit","period","comparison","region"]` 和 `evidence=true`。每条结果给出所属类型、实际字段、证据数量及至多四个带定位的引文。历史版本可以与当前版本在同一批中读取。
5. 某个旧条目只有标题和引文时，响应会将已定义但缺值的字段列入 `missing_fields`。对指标请求“公开立场”一类跨类型字段会出现在 `undefined_fields`。角色可以发起专项补证；数值 0 是有效数据。

规划器得到内容路由、相关字段和有限候选。研究角色可以通过 `knowledge_query` 指定目录、词项、实体及需要的字段，主动查到规划候选以外的资料。角色实际读取的版本和字段会随任务保存，重试可以复现研究输入。最终引用仍需明确的编号、版本与事件相关性理由。[角色协议](../evosight/contracts.py) · [规划、读取及发布](../evosight/research.py)

## 存储与索引

| 访问方式 | 存储和索引 |
| --- | --- |
| 发现目录、浏览子树 | `world_directories` 保存父子关系，`world_catalog_members` 按资料域、路径、记录时间、条目编号建立组合索引。目录数量区分直接条目与含子目录的总数。 |
| 搜索名称、别名、版本号、正文 | 中日韩统一表意文字采用相邻双字词，英文与版本号保留词边界，目录登记中英文别名。倒排索引以词项和条目编号为键，主体与已核验实体别名的权重高于正文。 |
| 精确限定统计期、地区或其他属性 | 同一倒排表为每个已核实字段建立含类型和字段名的精确键。多个限定条件取交集。当条目更新时，旧字段值只留在固定版本里。缺失的字段不会命中过滤条件。 |
| 指定实体或时间、找最近更新 | 当前条目另外按实体、发生时间、记录时间建索引。只有日期精度的证据可以进入按日检索，缺少发生时间的证据仍可通过其他入口查到。 |
| 固定版本、选取字段 | `world_versions` 把条目映射到不可变声明，`world_record_data` 按版本主键保存类型版本、目录和已核实的属性。版本不属于所请求条目时返回 `not_found`。 |
| 从旧预测回看、从条目找跟踪事件 | 预测版本关联事件索引快照，快照逐项引用声明版本，反向索引支持按声明定位引用方。角色读取、发布新版本与更新当前目录均通过数据库事务提交。 |

目录按内容增长，新增差异较大的类型时需同时增加字段释义、证据校验、样例查询与兼容测试。资料能落在父节点。未核实的字段在迁移后保留为空，既有原件、引文和历史事件索引保留原编号。[数据库定义](../evosight/workflow.sql) · [检索实现](../evosight/world_search.py)

## 检索验收

从三次真实试用留存的 26 条资料中，按内容预先选出每个问题的目标条目，覆盖 Vue 版本发布、国家统计局指标以及产品开售和功能。12 个开发问题的早期结果为 11 次前三命中，MRR@3 为 0.833。误差来自把自然问句中的虚词也当作主题词，以及共享前缀的版本号。改为保留完整版本号、优先完整主体、区分末级目录别名并识别问句中的常见虚词后，这 12 题的目标都排到首位。[逐题基线](../.work/catalog-baseline-01/metrics.json)

另在修改检索逻辑后、运行前单独定下 8 个问题，包括全角版本号、同月稿区分、统计指标和开售渠道。这 8 题的首次评测为 Hit@3 = 1.00、MRR@3 = 1.00。两个预期为空的检索也返回空结果。样本来自同一份小型档案，衡量范围仅限这些问题。代码按预期条目记录实际前三名，后续可以追加新事件中的失败查询。[首次结果及每题名次](../.work/catalog-eval-02/metrics.json) · [题目和复现脚本](../tests/benchmark_world_catalog.py)

在独立的 10,000 条合成资料库上，用 Windows 开发机、SQLite 3.50.4、热缓存，每种请求测量 80 次。按编码检索的 P95 为 0.125 毫秒，CPI 关键词为 2.657 毫秒，末级目录为 0.138 毫秒，发生日期范围为 0.194 毫秒，精确读取两条固定版本为 0.030 毫秒。单独定位类型及字段为 0.704 毫秒，统计目录内按统计月和地区联合筛选为 0.471 毫秒，统计目录各分支数量为 0.799 毫秒。耗时覆盖库内检索及结果构造。HTTP、模型推理和外部取证另计。SQLite 查询计划确认两个限定条件都走词项索引，目录和发生日期走各自的组合索引。[各项耗时与查询计划](../.work/catalog-qualifiers-eval-03/metrics.json)

对当前工作台、三个试用事件和已完成跨事件引用的试用库各做在线备份，在副本上连续启动两次。三个库分别核对 14 张原业务和知识表的逐行摘要。各库的 15、26、29 个历史声明版本均取得类型映射，两次启动的条目、版本、目录成员和索引项数量一致。当前工作台含 10 条真实世界知识及独立的演示资料。[迁移核对](../.work/catalog-upgrade-20261126-091443/audit.json)

### 真实 Agent 怎样处理一条旧指标

2026-11-26，在留存公开资料的隔离副本里，让 CANNBot Kimi K3.1 Pro 以测试档 low 处理“十月份居民消费价格同比及统计口径核验”。规划器自行选中居民消费价格目录，为专项研究指定七个字段。角色读到已有条目 17 的旧版本，七个目标字段均缺值，取得的原始依据是国家统计局列表第一段。第一次补证时，模型改写了旧结论，后端拒绝这项写入。角色按反馈只提交版本编号、字段和原文，经核验后发布。这一轮包含规划、两次专项角色调用和综合，共四次真实模型调用。[运行回执、目录查询和字段](../.work/catalog-agent-cpi/receipt.json)

同一个世界条目升至第 2 版。新事件的索引快照 7 固定了新版本，原有事件也可引用它。五个有原文依据的字段是指标名称“居民消费价格”、统计期“2026年10月”、数值 0.7、单位 %、比较基准“同比”。覆盖地区、统计口径均保留为缺失。界面列出同一份资料中的两处引句、两个引用事件，以及可回读的版本 1 和版本 2。[实际条目页面](../.work/catalog-browser-01/cpi-record.png)

在该真实试用库副本中按 `period=2026-10`、`comparison=同比` 联合精确检索，只返回条目 17 的新版本，换成九月会返回空结果。固定读取旧版本时，原先缺失的字段仍然为空。[按统计期与同比口径回读的结果](../.work/catalog-qualified-cpi/check.json)
